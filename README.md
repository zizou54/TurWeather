# TurWeather

A simple Streamlit app that shows the current weather and a 16-day forecast for any city.

- **Live weather data** comes from [Open-Meteo](https://open-meteo.com/). It's free and needs no API key.
- **OpenAI** writes a short, friendly summary of the conditions with advice on what to wear, and points out notable changes in the coming days.

## Features

- **Current conditions:** temperature, "feels like" temperature, humidity and wind, plus the city's local time.
- **16-day forecast:** a card for each day with the high and low temperature, chance of rain and maximum wind. 16 days is the most Open-Meteo provides.
- **AI summary:** generated by OpenAI from the current weather and forecast. Summaries are cached for 10 minutes, so re-displaying the same results doesn't call OpenAI again.
- **Refresh button:** next to **Get weather**. It clears the results and empties the City box. The API key in the sidebar is kept.
- **Dark mode:** a toggle at the top right switches between light and dark colors. It starts out matching your browser's theme, and each browser tab keeps its own setting.

## Setup

```bash
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add your OpenAI API key, or paste the key into the app's sidebar. To use a different model, set `OPENAI_MODEL` in `.env`; the default is `gpt-4o-mini`.

The weather data and forecast work without an API key. Only the AI summary needs one, and it needs credit on your OpenAI account.

## Run

```bash
streamlit run app.py
```

Then open http://localhost:8501, enter a city, and click **Get weather**.
